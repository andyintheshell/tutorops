# Security Policy

## Supported versions

TutorOps is currently under active development. Only the latest version
of the default branch is supported.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities through a public issue.

Report security concerns privately through GitHub's private vulnerability
reporting feature when available.

Include:

- the affected component or endpoint;
- reproduction steps;
- potential impact;
- any suggested remediation;
- whether the issue has been publicly disclosed.

Do not include real credentials, personal data, or third-party secrets
in a report.

## Response expectations

As a portfolio and learning project, TutorOps does not provide a
commercial response-time commitment. Reports will be acknowledged,
triaged, remediated when appropriate, and followed by a regression test
where technically practical.

## Scope

Security testing must use synthetic data and accounts controlled by the
tester. Do not test third-party identity providers, cloud services, or
other infrastructure without authorization.
